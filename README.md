## 📄 PDFWatcher

### Automatización Inteligente de Facturas

Este proyecto nació a partir de una conversación con un proveedor que necesitaba automatizar la organización de miles de facturas.

Desarrollé una aplicación en Python que monitorea carpetas en tiempo real y organiza automáticamente documentos utilizando OCR y cruces con información oficial de ARCA.

### Funcionalidades

- OCR Automático
- Matching mediante CAE
- Matching mediante CUIT
- Clasificación Inteligente
- Organización automática por proveedor y fecha
- Logs de diagnóstico
- Monitoreo en tiempo real

### Tecnologías

- Python
- Watchdog
- Tesseract OCR
- pdfplumber
- Pillow
